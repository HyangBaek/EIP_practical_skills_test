# 정보처리기사 실기 출제기준 (적용기간 2027.01.01 ~ 2029.12.31)

- 실기과목: 정보처리실무 · 검정방법: 필답형 · 시험시간: 2시간 30분

## 1. 요구사항 확인
- 현행 시스템 분석하기 (운영체제·DBMS·미들웨어 요구사항 식별, 목표 시스템 기술)
- 요구사항 확인하기 (요구사항 분석 기법, 검증 기준과 절차)
- 분석모델 확인하기 (요구사항 도출 기법, 분석모델 타당성 검토)

## 2. 데이터 입출력 구현
- 논리 데이터저장소 확인하기 (데이터 유형, 논리적 단위·관계, 제약조건)
- 물리 데이터저장소 설계하기 (물리 설계, 최적화, 저장 공간 구성)
- 데이터 조작 프로시저 작성하기 (연결·조회·저장 프로시저, 테스트 케이스)
- 데이터 조작 프로시저 최적화하기 (성능 예측·측정, 병목 파악)

## 3. 통합 구현
- 연계 데이터 구성하기 (내외부 모듈 간 연계 요구사항, 데이터 표준)
- 연계 메커니즘 구성하기 (송수신 방법, 연계 주기, 실패 처리, 송수신 보안)
- 내외부 연계 모듈 구현하기 (연계 모듈 구현, 무결성 검증, 단위 테스트)

## 4. 서버프로그램 구현
- 개발환경 구축하기 (HW·SW 설치·설정, 형상관리 환경)
- 공통 모듈 구현하기 (결합도는 낮추고 응집도는 높인 공통 모듈, 단위 테스트)
- 서버 프로그램 구현하기 (업무 프로세스, 보안 취약성 제거, 테스트)
- 배치 프로그램 구현하기 (배치 구현 기술, 하위 시스템 연동, 테스트)

## 5. 인터페이스 구현
- 인터페이스 설계서 확인하기 (공통 기능, 데이터 인터페이스, 데이터 표준)
- 인터페이스 기능 구현하기 (정형화된 인터페이스, 예외 처리, 인터페이스 보안)
- 인터페이스 구현 검증하기 (감시·검증 도구, 연계 상태 확인, 오류 처리 보고)

## 6. 화면 설계
- UI 요구사항 확인하기 (UI 표준·지침, 프로토타입)
- UI 설계하기 (UI 표준 반영 설계, 화면 흐름)

## 7. 애플리케이션 테스트 관리
- 애플리케이션 테스트케이스 설계하기 (테스트 케이스, 테스트 레벨, 시나리오)
- 애플리케이션 통합 테스트하기 (개발자 통합 테스트 계획·수행, 결함 관리)
- 애플리케이션 성능 개선하기 (성능 분석, 코드 최적화)

## 8. SQL 응용
- 절차형 SQL 작성하기 (프로시저·함수·트리거 등 반복 사용 SQL)
- 응용 SQL 작성하기 (윈도우 함수, 그룹 함수, DDL·DML·DCL, 조인·서브쿼리)

## 9. 소프트웨어 개발 보안 구축
- SW개발 보안 설계하기 (보안 요구사항, 보안 설계)
- SW개발 보안 구현하기 (시큐어 코딩, 보안 취약점, 보안 테스트)

## 10. 프로그래밍 언어 활용
- 기본문법 활용하기 (변수·자료형·연산자·제어문·배열·포인터·구조체·함수)
- 언어특성 활용하기 (C·Java·Python 언어별 특성, 객체지향: 상속·다형성·오버라이딩)
- 라이브러리 활용하기 (표준 라이브러리, 문자열·컬렉션 처리)

## 11. 응용 SW 기초 기술 활용
- 운영체제 기초 활용하기 (프로세스·스케줄링·메모리·페이지 교체, Linux 명령어)
- 데이터베이스 기초 활용하기 (DBMS 종류, 관계 모델, 정규화, 트랜잭션)
- 네트워크 기초 활용하기 (OSI·TCP/IP 계층, IP·서브넷, 라우팅, 프로토콜)
- 기본 개발환경 구축하기 (웹서버·DB서버·개발 도구 환경)

## 12. 제품소프트웨어 패키징
- 제품소프트웨어 패키징하기 (패키징·배포, DRM, 모니터링)
- 제품소프트웨어 매뉴얼 작성하기 (설치·사용자 매뉴얼, 국제 표준 품질 특성)
- 제품소프트웨어 버전관리하기 (형상관리 지침, 버전관리·빌드 자동화 도구)
